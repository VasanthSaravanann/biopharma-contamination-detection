**Multi-site Validation Plan (high level)**

Goals
-----
Validate performance and robustness across sites, instruments, and organisms.

Design
------
- Sites: 3 independent fermentation labs (pilot, academic, industrial partner)
- Batches per site: ≥20
- Organisms: at least 5 representative species (Gram-negative, Gram-positive, fungi)
- Inocula: 1, 10, 100 CFU/mL controlled spiking

Data collection
---------------
- Standardized sampling protocol (timepoints, instruments, file formats)
- Centralized manifest for train/test splits and ground-truth labels

Analysis plan
-------------
- Pre-registered statistical analysis (AUC primary endpoint)
- Site-wise and pooled analyses; random-effects meta-analysis for heterogeneity
